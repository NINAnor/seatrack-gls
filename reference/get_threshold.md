# get_threshold

Get the light threshold for a given logger model and mode (main or
summer).

## Usage

``` r
get_threshold(model, mode = c("main", "summer"))
```

## Arguments

- model:

  The logger model for which to get the light threshold.

- mode:

  The mode for which to get the light threshold, either "main" or
  "summer". Default is "main".

## Value

The light threshold value for the specified logger model and mode.
